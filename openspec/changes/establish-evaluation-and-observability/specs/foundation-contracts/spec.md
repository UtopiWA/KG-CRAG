# Spec Delta

## ADDED Requirements

### Requirement: 向后兼容的版本化评测 Trace
系统 SHALL 为统一评测提供严格、版本化的 Trace 事件契约，记录稳定 trace/run/question 标识、单调序号、阶段、事件、状态、时间戳、有界结构化明细和资源计数。新评测运行 MUST 使用新版本契约，既有 `TraceEvent v1` 及其落盘产物 MUST 保持可读取，并 SHALL 通过显式、确定性的适配结果参与统一报告；版本转换不得编造旧事件中不存在的信息。

#### Scenario: 新评测事件按版本校验
- **WHEN** 新评测运行产生带完整身份、单调序号、合法阶段/状态和有界明细的事件
- **THEN** 系统接受事件，并可仅依据公共字段关联运行、题目和逐题结果

#### Scenario: 旧版事件兼容读取
- **WHEN** 统一报告加载合法的 `TraceEvent v1` 产物
- **THEN** 系统保留原事件语义和来源版本，将缺失的新字段显式标记为未知或不适用，且不改写原文件

#### Scenario: 敏感、无界或版本未知的事件
- **WHEN** 事件包含凭据、完整 Prompt、私有推理、原始响应、未截断正文、超过上限的明细，或声明不受支持的 schema 版本
- **THEN** 系统拒绝该事件并返回可定位的契约错误，且不得将其写入 Agent 状态或评测产物
