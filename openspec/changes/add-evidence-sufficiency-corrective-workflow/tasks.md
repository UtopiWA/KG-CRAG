## 3. 构建覆盖矩阵与充分性判断

- [ ] 3.2 实现内部来源复核与外部证据隔离，测试缺失/漂移 Chunk、错误 Paper、失效 Graph 元数据及 `external=true` Evidence 均不能满足内部 facet。
- [ ] 3.3 实现版本化支撑强度和来源质量计算，测试缺失后端分数不会被伪造、不同 Evidence 类型使用合法字段且分数保持有限范围。
- [ ] 3.4 实现离散值、数值/单位和显式否定的保守冲突检测，测试冲突来源可回溯、未知单位保持待复核且不会静默选择高分证据。
- [ ] 3.5 实现逐 facet 最小来源数、支撑阈值、来源约束和阻断冲突聚合，测试首轮充分、比较缺侧、关键指标缺失、可选 facet 缺失和冲突阻断场景。
- [ ] 3.6 实现有界集合覆盖式 Evidence 选择，测试优先补足必需 facet、稳定去重、选定规模上限以及相同输入顺序扰动不改变结果。
